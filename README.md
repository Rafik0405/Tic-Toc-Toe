✅ Classic Tic Tac Toe Game – A simple two-player game where "X" and "O" take turns to win in a 3x3 grid.

💻 Built with Pure HTML, CSS, and JavaScript – No frameworks or libraries used, keeping it lightweight and easy to understand.

🧠 Smart Game Logic – Automatically detects wins, draws, and switches turns between players.

🎨 Clean and Responsive UI – Styled with CSS to be user-friendly and visually clean across devices.

🔁 Restart Game Feature – A reset button allows players to start a new round instantly.

🧱 Modular Code Structure – Separated files for HTML (index.html), CSS (style.css), and JS (script.js) for better readability and maintenance.

🖱️ Interactive Gameplay – Instant click response with real-time status updates (e.g., “Player X’s Turn”, “Player O Wins!”).

📱 Mobile-Friendly Layout – Responsive design ensures good experience on mobile and desktop (if implemented).

📂 Easy to Run Locally – Just open index.html in any browser—no server setup required.

🚀 Beginner-Friendly Project – Great starting point for learning basic DOM manipulation, event handling, and game logic in JavaScript.
